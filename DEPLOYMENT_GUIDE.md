# 🚀 Пошаговое руководство по развертыванию на Render

Ваш репозиторий полностью обновлен, закомичен и успешно отправлен на ваш аккаунт GitHub:
👉 **https://github.com/Mironsbl/Github-Trending-CLI**

Так как для автоматического развертывания через API Render требуются уникальные параметры вашего личного аккаунта (такие как `ownerId` и приватный токен Render API), вам нужно выполнить простую привязку репозитория в вашем кабинете Render вручную.

Следуйте этой инструкции для запуска сервиса в облаке за 2 минуты:

---

## Шаг 1. Создание веб-службы в Render

1. Зайдите в панель управления [Render Dashboard](https://dashboard.render.com/).
2. Нажмите кнопку **New +** в верхнем правом углу и выберите **Web Service**.
3. В списке репозиториев (Connect a repository) выберите **Github-Trending-CLI** (если аккаунт GitHub не подключен к Render, нажмите *Connect GitHub* и предоставьте доступ к созданному репозиторию).

---

## Шаг 2. Настройки веб-службы (Web Service Configuration)

Заполните поля настроек следующим образом:

* **Name:** `github-trending-dashboard` (или любое удобное вам имя)
* **Region:** Выберите любой регион (например, `Frankfurt (EU Central)`)
* **Branch:** `main`
* **Root Directory:** Оставьте пустым (по умолчанию используется корень проекта)
* **Runtime:** `Python 3` (или выберите Docker, так как в проекте есть готовый `Dockerfile`)
* **Build Command (если выбрали Python 3):**
  ```bash
  pip install -r requirements.txt
  ```
* **Start Command (если выбрали Python 3):**
  ```bash
  python main.py --web
  ```
* **Instance Type:** Выберите бесплатный тариф **Free**.

*(Если вы хотите запустить через Docker — просто выберите Runtime: **Docker**, и Render автоматически подхватит настройки из `Dockerfile` в корне проекта).*

---

## Шаг 3. Добавление переменных окружения (Environment Variables)

Вкладка **Advanced > Add Environment Variable**. Добавьте следующие ключи:

1. **`PORT`**: `10000` (Render использует порт `10000` по умолчанию для веб-сервисов)
2. **`HOST`**: `0.0.0.0`
3. **`FLASK_SECRET_KEY`**: Создайте случайную строку (например, `super-secret-production-key-135`)
4. **`GEMINI_API_KEY`**: Ваш API-ключ Gemini (чтобы работал ИИ-помощник, аудит зависимостей и сравнение репозиториев)
5. **`GITHUB_TOKEN`**: Ваш персональный токен GitHub (для обхода ограничений на количество запросов к API GitHub при парсинге README)

---

## Шаг 4. Готово!

Нажмите кнопку **Create Web Service** внизу страницы. 

Render автоматически:
1. Скачает ваш код с GitHub.
2. Соберет проект и установит зависимости.
3. Запустит сервис и выдаст вам публичный адрес вида `https://github-trending-dashboard.onrender.com`.

При любом последующем `git push` в репозиторий Render будет автоматически собирать и выкатывать обновления.
